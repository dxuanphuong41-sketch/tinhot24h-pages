# TikTok App Pages

Day la bo trang `https` mau de ban dua len GitHub Pages hoac hosting tinh.

## Cach dung nhanh voi GitHub Pages

1. Tao mot repo GitHub moi, vi du: `tinhot24h-pages`
2. Upload toan bo noi dung thu muc nay len repo do
3. Bat GitHub Pages cho nhanh `main` branch / root
4. Sau khi co link, URL se co dang:

`https://<github-username>.github.io/tinhot24h-pages/`

## Cac link can dien vao TikTok Developer

- Web/Desktop URL:
  `https://<github-username>.github.io/tinhot24h-pages/`
- Terms of Service URL:
  `https://<github-username>.github.io/tinhot24h-pages/terms.html`
- Privacy Policy URL:
  `https://<github-username>.github.io/tinhot24h-pages/privacy.html`
- Redirect URI:
  `https://<github-username>.github.io/tinhot24h-pages/callback/`

## Ghi chu

- Redirect URI trong dashboard TikTok phai trung khop 100%.
- Sau khi co redirect URI that, sua lai `TIKTOK_REDIRECT_URI` trong `telegram-bot.env`.
