Short video publishing workspace

tinhot24h

tinhot24h is a desktop workflow used by the owner of the channel Lướt Mạng Có Chuyện to create, review, and upload short-form videos. The application helps prepare commentary scripts, Vietnamese narration, subtitles, visual branding, and platform-ready video exports before the creator publishes them.

Purpose: assist one channel owner with a local video production and TikTok upload workflow.

Video preparation

Combine public or user-provided source material with a short Vietnamese commentary script, captions, and brand overlays.

Creator review

Generated videos remain under the creator's control. The owner reviews output, metadata, and platform requirements before posting.

Platform export

Export vertical short videos suitable for social platforms, including YouTube Shorts and TikTok draft upload flows.

How the application works

tinhot24h is not a public social network and does not host user accounts. It is a private desktop production tool operated by the channel owner. The workflow is intentionally simple and review-based.

1
Select content

The operator provides a source link or chooses a news/trend topic for a short video.

2
Create video

The tool generates narration, subtitles, overlays, and a rendered video file locally.

3
Review output

The creator checks the content, title, description, and compliance before upload.

4
Upload draft

When authorized, the TikTok API uploads the creator-approved file to the creator's TikTok account.

TikTok API integration

The app uses TikTok Login Kit so the channel owner can authorize their own TikTok account. It uses the Content Posting API only to upload videos created by the owner as drafts for further review in TikTok.

  • user.info.basic is used to confirm the authorized TikTok account.
  • video.upload is used to upload creator-approved video files as TikTok drafts.
  • The app does not automatically post public content without the creator's review.
  • The app does not sell data, read private third-party data, or manage other users' accounts.
